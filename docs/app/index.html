Membuka app…

Pasang di skrin utama telefon supaya boleh dibuka macam app biasa.

Buka App
iPhone (Safari atau Chrome)
  1. Tekan butang Kongsi (petak dengan anak panah ke atas). Di Chrome, butang ini ada di hujung kanan bar alamat.
  2. Pilih Add to Home Screen / Tambah ke Skrin Utama.
  3. Pastikan Open as Web App dihidupkan, kemudian tekan Add.
Android (Chrome)
  1. Tekan menu ⋮ di penjuru kanan atas.
  2. Pilih Add to Home screen / Install app.
